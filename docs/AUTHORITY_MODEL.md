# Authority Model

The Knowledge Tree routes to authority; it does not inherit authority from linked sources.

```text
RESEARCH ≠ RUNTIME
SPEC ≠ IMPLEMENTATION
IMPLEMENTATION ≠ ACTIVATION
TESTED ≠ PRODUCTION AUTHORIZED
RETRIEVAL ≠ EVIDENCE
EVIDENCE ≠ BELIEF
BELIEF ≠ TRUTH
CAPABILITY ≠ PERMISSION
MODEL OUTPUT ≠ CANON
JUDGE OUTPUT ≠ AUTHORITY
UNKNOWN ≠ FALSE
NOT RETRIEVED ≠ ABSENT
ATLAS ≠ OWNER
KNOWLEDGE TREE ≠ OWNER
CROSSWALK ≠ ATLAS
LAB ≠ PRODUCT
DISCUSSION ≠ EXECUTABLE EVIDENCE
SUMMARY ≠ SOURCE
LINK EXISTS ≠ SOURCE VERIFIED
CURRENT LABEL ≠ CURRENT TRUTH WITHOUT RECHECK
```

A node may be authoritative for a bounded question type, e.g. `frozen_run_output`, `long_form_research_history`, or `current_human_readable_status`. `not_authoritative_for` is equally important. The validator rejects overlaps between the two arrays.

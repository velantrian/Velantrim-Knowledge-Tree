# Reading Guide

## Start from the user's object

A user may provide a GitHub repo, a Drive doc, a Notion page, an experiment ID, or a concept. Resolve that object first; do not immediately load the whole ecosystem.

## Choose the source by question type

| Question | Preferred source |
|---|---|
| Exact implementation now? | live GitHub repository/ref |
| Frozen experiment output? | exact artifacts/tests/commit |
| Human-readable current status? | owning Notion page/current status doc |
| Why did research move from A to B? | Drive long-form history + reasoning log |
| What is related / where next? | Knowledge Tree + Atlas + Crosswalk |

Prefer one-hop expansion first. Follow a second hop only when it answers the question or resolves ambiguity.

`MORE CONTEXT ≠ BETTER CONTEXT`.

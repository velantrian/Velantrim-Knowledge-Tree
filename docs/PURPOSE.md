# Purpose

Velantrim Knowledge Tree preserves **discoverability and reopenability** across heterogeneous knowledge surfaces.

The problem is not only whether a document, repository, or research result still exists. The harder failure mode is that a future AI sees one fragment and does not know what else must be opened to reconstruct the context safely.

The Tree therefore stores compact routing metadata: identity, source system, role and maturity, why a source matters, explicit authority boundaries, typed relations, explanatory edge comments, reopen priority, and historical status.

Long-form content remains in its owning source. The Tree links to it rather than duplicating it.

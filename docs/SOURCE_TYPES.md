# Source Types

Supported `source_system` values: `GITHUB`, `GOOGLE_DRIVE`, `NOTION`, `WEB`, `LOCAL`, `OTHER`.

Supported node types include `ECOSYSTEM`, `DOMAIN`, `PROJECT`, `REPOSITORY`, `DOCUMENT`, `NOTION_PAGE`, `RESEARCH_THREAD`, `EXPERIMENT`, `ISSUE`, `PULL_REQUEST`, `ARTIFACT`, `CONCEPT`, `ARCHITECTURE_DOC`, `STATUS_DOC`, `REASONING_LOG`, `DISCUSSION_ARCHIVE`, `PROPOSAL`, `CULTURE_DOC`, `HISTORICAL_DOC`, `INDEX`, `OTHER`.

Source type says **where the object lives**, not what authority it has.

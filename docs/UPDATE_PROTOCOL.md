# Update Protocol

```text
NEW IMPORTANT KNOWLEDGE
        ↓
update owning source first
        ↓
update relevant Tree node / edge
        ↓
if a cross-project relation changed → update Crosswalk
        ↓
if global navigation changed → update Atlas
```

Rules: executable truth belongs in GitHub; current ownership/status belongs in the owning Notion surface when applicable; long-form discussion/research evolution belongs in Drive or a dedicated reasoning log; the Tree stores routing metadata rather than uncontrolled duplicates. Preserve historical mistakes when they explain research evolution. Never infer activation from documentation: `file exists ≠ tested ≠ enabled ≠ production`.

Before calling a branch complete ask: **Could another AI reopen the right deeper source without the original chat?**
